# 2026-09-13

## WebstudioWebsiteExample 多语言切换

将 `i18n/locales/` 默认语言从俄语切到中文：

- 新增 `i18n/locales/zh.json`（与 en.json 同构，153 键全对齐）
- 删除 `i18n/locales/ru.json`
- `nuxt.config.ts`：`defaultLocale: 'ru'` → `'zh'`；locales 改为 zh + en
- `app/app.vue`：加 `resolveUiLocale(code)` 把 i18n 的 `zh` 映射到 `@nuxt/ui/locale` 的 `zh_cn`，否则 Nuxt UI 拿到 undefined
- `README.md`：全文翻译为中文（原俄语）
- UrlStrategy 保持 `prefix_except_default`，`prerenderRoutes` 无需改

注意点：dev server 需重启以应用新 i18n 配置；Nuxt UI locale 的 key 是 BCP-47 风格（zh_cn），不是 ISO 639-1（zh）。
